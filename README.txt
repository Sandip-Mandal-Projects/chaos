THE OBSERVER — minimal mobile edition

This is a single-file, mobile-first website. It embeds your exact original eye image,
with no added text, no replacement artwork, no external libraries, and no assets folder.

To publish:
1. Replace the repository's old index.html with this index.html.
2. Commit/push the change to GitHub.
3. Wait for GitHub Pages deployment, then refresh the site.

The eye remains the main focus. It has subtle pointer/touch parallax and a very light
particle layer. Double-tap/click gives a brief green flash. It does not use the camera.
