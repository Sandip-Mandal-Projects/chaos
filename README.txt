SANDIP.LOL — THE INTERNET THAT SHOULDN'T EXIST
================================================

This is a standalone static HTML/CSS/JavaScript interactive fake operating system.

Included:
- Fictional BIOS/boot screen
- Responsive desktop with movable, minimizable, maximizable, closable app windows
- Fake file explorer and fictional file contents
- Toy terminal with safe built-in commands only (does not execute operating-system commands)
- Fictional browser with internal pages (/404, /truth, /void)
- Notepad with local browser storage
- Mini arcade game with locally saved best score
- Hidden archive and easter eggs
- Links to the creator's portfolio and Sandip Lab
- Mobile responsive layout, keyboard shortcuts, reduced-motion support
- No backend, accounts, cookies, or autoplay audio

PREVIEW
Open index.html in a modern browser. Google Fonts are optional; system fallbacks are provided.
Some browser storage or clipboard features may behave differently when opened from file://; hosting over HTTPS is recommended.

DEPLOY
1. Extract this ZIP.
2. Deploy the folder containing index.html to your static host (e.g. Vercel).
3. Assign sandip.lol in the host's domain settings and configure DNS as instructed by the host.
4. Test desktop and mobile views after deployment.

NOTE
The fake terminal is deliberately restricted to a few harmless fictional commands. This is not a real OS and does not inspect or modify visitor files.
Notes and best score are saved only in the visitor's browser using localStorage. No server is used.
